# my-portfolio
This portfolio demonstrates my work combining digital media, traditional art concepts, and web development. The website includes interactive stars and constellation animations, project showcase cards, dark/light mode toggle, and an About Me section.

Features

Dark/Light Mode: Toggle between themes for a personalized viewing experience.

Animated Background: Aquarius-inspired flowing background and floating stars.

Constellation Lines: Animated lines connect clickable stars.

Clickable Stars: Easter egg messages appear when stars are clicked.

Interactive Project Cards: Hover effects and links to live projects.

About Me Section: Learn more about me and my skills.

Social Links: Direct links to Instagram and LinkedIn.
